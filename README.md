# Flavourzy Café

A modern, friendly, illustration- and food-photography-driven landing page for **Flavourzy Café** (Charni Road, Mumbai) built with Next.js (App Router), React 19, TypeScript, Tailwind CSS, Motion, and Lenis smooth scrolling.

## Tech Stack
- **Framework**: Next.js 16 (App Router with Turbopack)
- **Library**: React 19
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Motion**: Motion (`motion/react`)
- **Smooth Scroll**: Lenis
- **Icons**: Lucide React + Custom SVGs

## Getting Started

First, install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Build for Production

```bash
npm run build
npm start
```
